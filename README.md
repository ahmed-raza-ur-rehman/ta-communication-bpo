# TA Communication

A multi-page executive outreach and BPO marketing website for TA Communication.

## Development

```powershell
npm.cmd install
npm.cmd run dev
```

## Production build

```powershell
npm.cmd run build
npm.cmd run preview
```

The site is a Vite-powered static application. It includes Home, About, Services, MVA, Final Expense, Lead Generation, Digital Marketing, and Contact pages.
